Ficha técnica: Python

Información general

Python es un lenguaje de programación de alto nivel. Su primera versión pública fue lanzada el 20 de febrero de 1991.

Python se utiliza para desarrollar aplicaciones, automatizar tareas y trabajar con datos.

Características principales

Python es un lenguaje interpretado. Un lenguaje interpretado es aquel cuyo código se ejecuta mediante un programa llamado intérprete.

También es muy utilizado en el desarrollo de aplicaciones y permite escribir código de forma sencilla.

Ejemplo de código

Este es un ejemplo de código escrito en Python:

print("Hola, mundo")

Herramientas de programación

Python se puede utilizar en diferentes IDE, como Visual Studio Code.

Para guardar un archivo en Visual Studio Code, podemos utilizar la combinación de teclas Ctrl + S.

Versión

Actualmente, Python cuenta con diferentes versiones. Por ejemplo, Python 3rd es una forma de representar una versión de tercera generación.
