## ¿Cuál de las tres formas es la más cómoda si tuviera que cambiar el color del título en 10 páginas?
La forma más cómoda es utilizar un archivo CSS externo. De esta manera, podemos cambiar el color del título una sola vez en `estilos.css` y el cambio se aplicará a las 10 páginas.

## ¿Por qué se desaconseja la primera?
La primera forma, utilizando el atributo `style`, se desaconseja porque hay que escribir el CSS dentro de cada elemento. Si tenemos muchas páginas, sería más difícil modificar los estilos y mantener el código organizado.
