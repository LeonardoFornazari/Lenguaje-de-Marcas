HTML

HTML es un lenguaje de marcado que se utiliza para crear la estructura de las páginas web. Permite organizar el contenido mediante elementos como títulos, párrafos, imágenes, enlaces y listas.

Las páginas HTML utilizan etiquetas para indicar qué tipo de contenido se está mostrando. Por ejemplo, la etiqueta h1 representa el título principal de una página, mientras que la etiqueta p representa un párrafo de texto.

También podemos utilizar enlaces para conectar diferentes páginas o para desplazarnos a distintas partes de un mismo documento. Para ello utilizamos la etiqueta a junto con el atributo href.

HTML es uno de los conocimientos fundamentales para cualquier persona que quiera aprender desarrollo web. Es el punto de partida para construir páginas y aplicaciones web.

CSS

CSS es un lenguaje que permite dar estilo a las páginas web. Se utiliza para modificar colores, tamaños de texto, fondos, bordes, márgenes y espacios entre los diferentes elementos.

Podemos escribir CSS directamente en un documento HTML, pero lo más recomendable es utilizar un archivo externo con extensión .css. De esta manera, podemos separar el contenido de la presentación.

CSS también permite organizar los elementos de una página. Algunas de sus propiedades más conocidas son display, margin, padding, position y width.

Gracias a CSS podemos crear páginas web más atractivas, ordenadas y fáciles de utilizar. También podemos adaptar su diseño a diferentes tamaños de pantalla.

JavaScript

JavaScript es un lenguaje de programación utilizado principalmente para añadir interactividad a las páginas web. Permite que una página pueda reaccionar a las acciones de los usuarios.

Por ejemplo, podemos utilizar JavaScript para crear botones interactivos, validar formularios, mostrar mensajes o modificar el contenido de una página sin tener que recargarla.

JavaScript trabaja junto con HTML y CSS. HTML define la estructura, CSS se encarga del diseño y JavaScript permite añadir comportamiento e interacción.

Es uno de los lenguajes más importantes del desarrollo web y también se puede utilizar en el desarrollo del lado del servidor mediante entornos como Node.js.

Herramientas de desarrollo

Para desarrollar páginas web necesitamos diferentes herramientas que nos ayuden a escribir, organizar y comprobar nuestro código.

Visual Studio Code es un editor de código muy utilizado por los desarrolladores. Permite trabajar con HTML, CSS, JavaScript y muchos otros lenguajes.

También podemos utilizar Live Server para visualizar una página web en el navegador y comprobar los cambios que hacemos mientras trabajamos.

Git y GitHub son herramientas que permiten guardar y gestionar los cambios de nuestros proyectos. También facilitan compartir el código y trabajar en equipo.
